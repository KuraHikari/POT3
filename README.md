# POT3

Proyecto Java preparado para trabajar en IntelliJ IDEA.

## Abrir y ejecutar

1. En IntelliJ IDEA, selecciona **File → Open** y abre la carpeta **POT3** que contiene este README.
2. Si aparece el aviso de confianza, confirma que confías en el proyecto.
3. Abre `src/Main.java` y pulsa el triángulo verde junto a `main` para ejecutar.

La configuración utiliza el JDK `homebrew-25` instalado en este equipo, con nivel de lenguaje Java 17 y codificación UTF-8. En otro equipo, selecciona un JDK 17 o superior en **File → Project Structure → Project SDK**.

## Estructura

- `src/Main.java`: punto de entrada del programa.
- `POT3.iml` y `.idea/`: configuración del proyecto de IntelliJ IDEA.
- `.gitignore`: excluye archivos compilados y ajustes personales.

La carpeta `out/` se genera al compilar y no se sube a GitHub.
